# AI-only-game
🎰 Roulette 3D — Unity Game
A full 3D roulette game built in Unity, featuring a realistic spinning wheel, rolling ball physics, and a complete betting system. The game recreates the full casino experience with a functional table layout, wager system, and number detection.

🎯 Features
🎡 Realistic Roulette Wheel
Fully animated spinning wheel

Smooth deceleration

Accurate ball physics

Ball falls into a numbered slot

💵 Betting & Money System
Player balance

Adjustable wager amounts

Win/lose payouts based on real roulette rules

Outside bets (red/black and number bets)

🃏 Full Roulette Table Layout
Interactive table UI

Clean 3D environment

🧠 Game Logic
Randomized spin results

Slot detection using colliders

Automatic payout calculation

Reset for next round

🎮 Goal of the Project
To build a complete, functional roulette game in Unity with all the mechanics you’d expect from a real casino table — wheel, ball, bets, payouts, and presentation.
